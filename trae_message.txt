三、冲突解决方案
============================================================
已创建智能部署系统，位于 f:/solo/ 目录：

1. deploy_smart.py - 智能部署脚本
   - 部署前自动检测文件冲突
   - 自动备份被覆盖的文件到服务器 backups/ 目录
   - 记录部署历史，避免重复部署

2. check_conflict.py - 冲突检测脚本
   - 部署前检查本地与远程文件差异
   - 显示详细冲突报告

3. merge_conflict.py - 冲突合并工具
   - 查看文件差异（彩色显示）
   - 选择保留本地或远程版本

使用流程：
  python check_conflict.py    # 检测冲突
  python merge_conflict.py    # 合并冲突（如有）
  python deploy_smart.py      # 智能部署
