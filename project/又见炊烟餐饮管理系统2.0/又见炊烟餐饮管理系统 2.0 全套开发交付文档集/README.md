## 重要通用约束（所有开发人员必读）

1. 所有业务表禁止物理DELETE删除，统一使用 `is_deleted` 逻辑删除；
2. 全系统金额统一使用 `decimal(12,2)`，禁止使用浮点类型；
3. 所有业务操作必须留存审计日志audit_log；
4. 所有状态枚举统一参考【01_产品PRD/全局状态字典统一标准文档.md】，禁止各自定义状态值；
5. 所有SQL脚本统一编码：UTF-8；文档命名不含特殊字符，Windows/Mac/Linux全平台兼容；
6. 所有HTTP请求必须包含 `storeId` 参数（多门店隔离）；
7. 非登录接口必须携带 `Authorization: Bearer <JWT>`；
8. 金额联动控件（价格/折扣/成本率）使用 `lastEditSource` 标志防止循环更新；
9. **文档统一使用 .md 后缀**，禁止与 .docx 混用，避免目录索引混乱；
10. **数据库变更必须 Flyway 迁移脚本 + CHANGELOG.md 双记录**（详见 02_数据库设计/数据字典与DDL同步规范.md）；
11. **客户手机号必须脱敏存储与展示**，详情查看需二次授权（详见 03_接口规范/安全规范_餐饮行业专属.md）；
12. **WebSocket 消息必须保证幂等性**，重连后自动拉取离线消息（详见 06_WebSocket异步通信/断线重连与消息可靠性规范.md）；
13. **Commit 提交必须遵循** `【工具名】模块-操作：内容` 格式 + feat/fix/refactor/docs/test 前缀（详见 03_接口规范/Git分支管理规范.md）。
