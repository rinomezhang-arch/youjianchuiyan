## 版本说明

### 版本号规则
- **主版本号**：不兼容的重大架构变更
- **次版本号**：新增功能，向下兼容
- **修订号**：问题修复，向下兼容

### 变更类型
- **Added**：新增内容
- **Changed**：内容变更
- **Deprecated**：即将废弃
- **Removed**：已移除
- **Fixed**：问题修复
- **Security**：安全相关
