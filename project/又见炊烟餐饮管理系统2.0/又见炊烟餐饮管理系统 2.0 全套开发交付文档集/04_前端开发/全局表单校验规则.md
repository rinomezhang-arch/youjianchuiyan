## 1. 通用规则

### 1.1 el-form 配置

```vue
<el-form
  ref="formRef"
  :model="formData"
  :rules="formRules"
  label-width="100px"
  label-position="top"
  size="default"
>
  <el-form-item label="客户姓名" prop="customerName">
    <el-input v-model="formData.customerName" placeholder="请输入" />
  </el-form-item>
</el-form>
```

### 1.2 校验触发
- `trigger: 'blur'`：失焦校验（默认，文本类）
- `trigger: 'change'`：变更校验（选择类、数字类）
- `trigger: ['blur', 'change']`：双触发

## 2. 字段类型规则

### 2.1 文本

| 字段 | 规则 | 示例 |
|------|------|------|
| 必填文本 | `required: true, message: '不能为空', trigger: 'blur'` | 客户姓名 |
| 长度限制 | `min: 2, max: 50, message: '长度 2~50'` | 备注 |
| 中文名 | `pattern: /^[\u4e00-\u9fa5]{2,20}$/` | 员工姓名 |


### 2.4 邮箱


### 2.5 金额

```js
amount: [
  { required: true, message: '请输入金额', trigger: 'blur' },
  { type: 'number', min: 0, message: '金额必须 ≥0', trigger: 'blur' },
  { validator: validateDecimal2, trigger: 'blur' }
]

// 自定义校验器：最多 2 位小数
const validateDecimal2 = (rule, value, callback) => {
  if (!/^\d+(\.\d{1,2})?$/.test(value)) {
    callback(new Error('金额最多 2 位小数'))
  } else {
    callback()
  }
}
```

### 2.6 百分比

```js
discount: [
  { type: 'number', min: 0, max: 100, message: '范围 0~100', trigger: 'change' }
]
```
配合 `el-input-number :min="0" :max="100" :step="1"`。

### 2.7 日期

```js
bookingDate: [
  { required: true, message: '请选择日期', trigger: 'change' },
  { validator: validateFutureDate, trigger: 'change' }
]

// 不能早于今天
const validateFutureDate = (rule, value, callback) => {
  if (new Date(value) < new Date(new Date().toDateString())) {
    callback(new Error('日期不能早于今天'))
  } else {
    callback()
  }
}
```

## 3. 业务规则校验

### 3.1 人数联动（套餐）

最低人数 ≤ 最高人数，且修改时联动：
- `min === max` → 点 `-` on max → 同时减少
- `min < max` → 点 `-` on max → 仅减 max
- 点 `+` on min → 若 min+1 > max，自动 max=min+1
- 点 `-` on min → 仅减 min
- 点 `+` on max → 仅增 max

```js
const onMinChange = (val) => {
  if (val > formData.maxGuests) {
    formData.maxGuests = val
  }
}
const onMaxDecrease = (val) => {
  if (formData.minGuests === formData.maxGuests) {
    formData.minGuests = val
  }
}
```

### 3.2 价格联动（套餐）

价格/折扣/成本率三联动，用 `lastEditSource` 防循环：
```js
watch(() => formData.discount, (val) => {
  if (lastEditSource.value === 'discount') return
  lastEditSource.value = 'discount'
  formData.price = formData.originalPrice * val / 100
  formData.costRate = formData.cost / formData.price * 100
  nextTick(() => lastEditSource.value = null)
})
```

### 3.3 桌台占用检查

预订创建/修改前调后端接口检查桌台占用：
```js
const checkTableAvailability = async (tableIds, date) => {
  const res = await api.post('/api/tables/check-availability', { tableIds, date })
  if (res.data.code !== 200) {
    return res.data.message  // 返回占用提示
  }
  return null
}
```

## 4. 提交流程

### 4.1 保存流程（套餐为例）

```
点击保存 → 数据审计 → 失败？
                      ├ 是 → 2 秒闪现告警 + 激活对应控件
                      └ 否 → 弹"确认保存" → 二次审计 → 落库
```

```js
const doSave = async () => {
  // 1. 表单校验
  await formRef.value.validate()

  // 2. 业务审计
  const auditResult = auditPackageData(formData)
  if (!auditResult.valid) {
    flashAlert(auditResult.message, 2000)
    focusControl(auditResult.fieldName)
    return
  }

  // 3. 弹"确认保存"
  await ElMessageBox.confirm('确认保存？', '提示', { type: 'warning' })

  // 4. 二次审计
  const reAudit = auditPackageData(formData)
  if (!reAudit.valid) {
    ElMessage.error('数据已变化，请重新检查')
    return
  }

  // 5. 落库
  await api.post('/api/packages', formData)
  ElMessage.success('保存成功')
}
```

### 4.2 删除前确认

```js
const doDelete = async (id) => {
  await ElMessageBox.confirm('确认删除？此操作不可恢复', '警告', {
    type: 'warning',
    confirmButtonText: '确定删除',
    cancelButtonText: '取消'
  })
  await api.delete(`/api/customers/${id}`)
  ElMessage.success('已删除')
  loadList()
}
```

## 5. 错误提示样式

### 5.1 表单内错误
- el-form-item 默认下方红字
- 错误时输入框红框

### 5.2 全局提示
- `ElMessage.success/info/warning/error`
- 持续 3 秒自动消失
- 顶部居中显示

### 5.3 闪现告警（套餐审计用）
```js
const flashAlert = (message, duration = 2000) => {
  const alert = ElMessage({
    message,
    type: 'warning',
    duration
  })
}
```

## 6. 移动端适配

### 6.1 输入框
- 高度 32px（紧凑）
- 宽度自适应
- 禁用浏览器自动缩放：`font-size: 16px`

### 6.2 选择器
- 用底部滑动 drawer 替代居中 dialog
- 原生 `<select>` 替代 el-select（移动端体验）

### 6.3 弹窗
- 宽度 50vw（PC）/ 90vw（移动）
- 圆角 16px
- 按钮组居中

## 7. 校验规则文件组织

建议在 `frontend_v3/src/utils/rules.js` 集中导出可复用规则：

```js
// frontend_v3/src/utils/rules.js
export const required = (msg = '不能为空') => ({ required: true, message: msg, trigger: 'blur' })
export const phone = [
  { required: true, message: '请输入手机号', trigger: 'blur' },
  { pattern: /^1[3-9]\d{9}$/, message: '手机号格式不正确', trigger: 'blur' }
]
export const amount = [
  { type: 'number', min: 0, message: '金额必须 ≥0', trigger: 'blur' },
  { validator: validateDecimal2, trigger: 'blur' }
]
```

页面引用：
```js
import { phone, amount } from '@/utils/rules'
const rules = { customerPhone: phone, totalAmount: amount }
```
