# 系统可配置参数 & 业务规则说明书

> 版本：V2.0  | 创建日期：2026-08-02 | 维护：产品经理(天龙)

---

## 1. 文档说明

本文档汇总又见炊烟餐饮管理系统 2.0 全部可配置参数与业务规则。所有参数均存储于 `config` 表，支持全局默认（store_id=0）与分门店差异化（store_id=1/2）两档配置。分门店配置采用 `<rule>__s<store_id>` 命名约定，读取时优先取门店配置，未命中则回退全局默认。业务规则为参数在业务流程中的执行约束，配合状态字典共同构成系统行为准则。

### 1.1 配置表结构

| 字段 | 类型 | 说明 |
|------|------|------|
| config_key | VARCHAR(100) PK | 配置键，全局唯一 |
| config_value | VARCHAR(500) | 配置值（字符串存储，按类型解析） |
| store_id | BIGINT | 0=全局，1=宁国店，2=宣城店 |
| created_at / updated_at | DATETIME | 时间戳 |

### 1.2 配置方式
- 数据库直接 UPDATE `config` 表
- 后续提供 GM 后台「系统设置-业务规则」页面可视化配置（菜单 `/dashboard/settings`，权限 `system:perm`）
- 修改后实时生效，无需重启

## 4. 参数与规则维护流程

1. **变更申请**：业务方提出参数/规则变更需求，说明影响范围。
2. **GM 审批**：GM 在「系统设置-业务规则」页面修改参数并提交，操作审计留痕。
3. **即时生效**：参数写入 `config` 表后实时生效，无需重启服务。
4. **影响验证**：变更后在测试环境验证相关业务流程，确认无异常。
5. **回滚预案**：保留变更前参数值，异常时可一键回滚。
