## 4. 请求处理流程

```
HTTP 请求
   │
   ▼

   │
   ▼
[EncodingFilter] UTF-8 强制编码
   │
   ▼
[CorsFilter] 跨域处理
   │
   ▼
[JwtAuthInterceptor] 鉴权 → 注入 UserContext
   │
   ▼
[RateLimitInterceptor] 限流
   │
   ▼
[StoreDataScopeAspect] 门店数据范围注入
   │
   ▼
[Controller] 业务方法
   │
   ▼
[Service] 事务 + 业务逻辑
   │
   ▼
[Repository] 数据访问
   │
   ▼
[MySQL]
   │
   ▼
[AuditLogAspect] 操作记录（REQUIRES_NEW 独立事务）
   │
   ▼
[NotifyPublisher] 通知（落库 + MQ 异步）
   │
   ▼
[GlobalExceptionHandler] 异常兜底
   │
   ▼
HTTP 响应 Result<T>
```

## 6. 数据流

### 6.1 同步流（数据库）
```
前端 → axios → request.js → Nginx → Controller → Service → Repository → MySQL
                                                                    ↓
                                                              返回 Result<T>
```

### 6.2 异步流（MQ 通知）
```
Service 业务操作
     ↓
NotifyPublisher.publish(event)
     ├──→ MySQL.sys_notification (同步落库)
     └──→ RabbitMQ.youjian.notify.exchange (异步推送)
                ↓
         NotifyConsumer.onNotify
                ├──→ [TODO] WebSocket → KDS 厨房屏
                ├──→ [TODO] WebSocket → 前台看板
                └──→ [TODO] 短信通道
```

## 8. 关键设计决策

### 8.1 多租户隔离
- 所有业务表强制 `store_id` 字段
- AOP 切面自动注入数据范围
- 写接口必须 `assertStoreAccess` 越权断言

### 8.2 软删除
- 禁止物理 DELETE
- 统一 `is_active=0` 软删除
- 查询必须过滤 `is_active=1`

### 8.3 配置中心
- 业务规则配置集中在 `config` 表（30+ 项）
- 字典集中在 `sys_dict` / `sys_dict_item`（17 类）
- 环境配置通过 `application.yml` + 环境变量

### 8.4 异常处理
- Controller 内 try-catch + `setRollbackOnly()` 显式回滚
- 全局 `GlobalExceptionHandler` 兜底
- 统一返回 `Result<T>` 中文错误信息

### 8.5 RabbitMQ 降级
- `app.notify.enabled=false`（默认）时无 MQ 也能启动
- 生产者始终同步落库兜底
- MQ 发送失败仅记录日志，不阻断主流程

## 9. 扩展性

### 9.1 横向扩展
- 后端无状态，可多实例 + Nginx 负载均衡
- MySQL 主从复制（读写分离）
- RabbitMQ 集群

### 9.2 纵向扩展
- 加缓存（Redis，待引入）
- 读写分离（MySQL Proxy）
- 分库分表（按 store_id 分片）

## 10. 安全

- JWT 鉴权
- AES 加密敏感字段（身份证、银行卡）
- AESUtil 密钥环境变量 `AES_SECRET_KEY`
- 数据脱敏（`SensitiveDataSerializer` / `IdCardSerializer`）
- 接口限流（`RateLimitInterceptor`）
- CORS 跨域白名单
- 审计日志全留痕
