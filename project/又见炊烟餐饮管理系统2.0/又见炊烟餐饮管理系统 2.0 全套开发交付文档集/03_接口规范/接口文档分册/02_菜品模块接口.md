| 项目 | 内容 |
|------|------|
| 模块名称 | 菜品模块 |
| Controller 数量 | 4 |
| 覆盖 Controller | DishController / RecipeController / IngredientController / MenuCategoryController |
| 维护人 | 又见炊烟研发组 |

## 通用约定

### 全局请求头

| 请求头 | 必填 | 说明 |
|--------|------|------|
| storeId | 是 | 门店 ID，用于多门店数据隔离 |
| Authorization | 是 | `Bearer <JWT>` |
| Content-Type | 否 | POST/PUT 为 application/json |

### 全局响应格式

```json
{ "code": 0, "message": "success", "data": {} }
```

### 通用错误码

| code | 含义 | 触发场景 |
|------|------|----------|
| 0 | success | 请求成功 |
| 1001 | 参数校验失败 | 必填参数缺失 |
| 1002 | 请求体格式错误 | JSON 解析失败 |
| 1003 | 重复数据 | 菜品名 / 编码重复 |
| 2001 | 未登录 / Token 失效 | 缺少 Authorization |
| 2002 | Token 过期 | JWT 超时 |
| 3001 | 无操作权限 | 角色无权限 |
| 3002 | 越权访问 | 跨门店访问 |
| 4001 | 记录不存在 | 主键查询为空 |
| 4002 | 记录已被删除 | 命中逻辑删除标记 |
| 4003 | 状态不允许操作 | 菜品已售罄等 |
| 5000 | 业务异常 | BusinessException |
| 9000 | 系统异常 | 未捕获异常 |

### 通用分页参数

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| page | Integer | 否 | 页码，默认 1 |
| size | Integer | 否 | 每页条数，默认 10 |
| keyword | String | 否 | 模糊搜索关键字 |

## 2.1 DishController 菜品信息

- **类映射前缀**：`/dish`
- **完整路径示例**：`/api/dish/list`
- **说明**：菜品档案、分类、上下架 / 售罄状态维护。

### 2.1.1 菜品列表

- **方法**：GET
- **路径**：`/api/dish/list`
- **请求头**：storeId、Authorization

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| page | Integer | 否 | 页码，默认 1 |
| size | Integer | 否 | 每页条数，默认 10 |
| keyword | String | 否 | 菜品名称模糊搜索 |
| categoryId | Long | 否 | 分类 ID |
| status | Integer | 否 | 状态：1 在售 / 0 下架 / 2 售罄 |

- **响应示例**：

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "total": 120,
    "page": 1,
    "size": 10,
    "records": [
      {
        "dishId": 1001,
        "dishName": "宫保鸡丁",
        "dishNo": "CP-1001",
        "categoryId": 5,
        "categoryName": "川菜",
        "price": 38.00,
        "unit": "份",
        "image": "/upload/dish/1001.jpg",
        "status": 1,
        "storeId": 1
      }
    ]
  }
}
```

- **错误码**：0 / 2001 / 9000

### 2.1.2 菜品详情

- **方法**：GET
- **路径**：`/api/dish/{id}`
- **请求头**：storeId、Authorization

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| id | Long | 是 | 菜品 ID（路径参数） |

- **响应示例**：

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "dishId": 1001,
    "dishName": "宫保鸡丁",
    "dishNo": "CP-1001",
    "categoryId": 5,
    "price": 38.00,
    "cost": 18.00,
    "unit": "份",
    "image": "/upload/dish/1001.jpg",
    "description": "经典川菜，麻辣鲜香",
    "status": 1,
    "storeId": 1
  }
}
```

- **错误码**：0 / 4001 / 4002 / 3002

### 2.1.3 新增菜品

- **方法**：POST
- **路径**：`/api/dish`
- **请求头**：storeId、Authorization

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| dishName | String | 是 | 菜品名称 |
| dishNo | String | 否 | 菜品编码 |
| categoryId | Long | 是 | 分类 ID |
| price | BigDecimal | 是 | 售价 |
| cost | BigDecimal | 否 | 成本价 |
| unit | String | 是 | 单位：份 / 斤 / 份 |
| image | String | 否 | 图片地址 |
| description | String | 否 | 描述 |

- **响应示例**：

```json
{ "code": 0, "message": "success", "data": { "dishId": 1002 } }
```

- **错误码**：0 / 1001 / 1003（菜品名重复）

| 参数名 | 类型 | 必填 | 说明 |

## 2.2 RecipeController 食谱管理

- **类映射前缀**：`/recipe`
- **完整路径示例**：`/api/recipe/{dishId}`
- **说明**：菜品用料配方（BOM），支持按配方重算成本。

### 2.2.1 查询菜品食谱

- **方法**：GET
- **路径**：`/api/recipe/{dishId}`
- **请求头**：storeId、Authorization

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| dishId | Long | 是 | 菜品 ID（路径参数） |

- **响应示例**：

```json
{
  "code": 0,
  "message": "success",
  "data": [
    {
      "recipeId": 1,
      "dishId": 1001,
      "ingredientId": 201,
      "ingredientName": "鸡腿肉",
      "quantity": 0.3,
      "unit": "斤",
      "cost": 6.00
    }
  ]
}
```

- **错误码**：0 / 4001 / 3002

### 2.2.2 保存菜品食谱

- **方法**：POST
- **路径**：`/api/recipe/{dishId}`
- **请求头**：storeId、Authorization

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| dishId | Long | 是 | 菜品 ID（路径参数） |
| items | Array | 是 | 用料明细数组 |
| items[].ingredientId | Long | 是 | 原料 ID |
| items[].quantity | BigDecimal | 是 | 用量 |
| items[].unit | String | 是 | 单位 |

- **响应示例**：

```json
{ "code": 0, "message": "success", "data": { "dishId": 1001, "totalCost": 18.00 } }
```

- **错误码**：0 / 1001 / 4001（菜品不存在）/ 5000（事务回滚）

### 2.2.3 含配方的菜品列表

- **方法**：GET
- **路径**：`/api/recipe/dishes-with-recipe`
- **请求头**：storeId、Authorization

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|

```json
  "code": 0,
  "message": "success",
  "data": [

  ]
}
```

- **错误码**：0 / 2001

### 2.2.4 重算所有菜品成本

- **方法**：POST
- **路径**：`/api/recipe/recalc-all`
- **请求头**：storeId、Authorization

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| 无 | - | - | 按 storeId 重算 |

- **响应示例**：

```json
{ "code": 0, "message": "success", "data": { "recalculated": 120 } }
```

- **错误码**：0 / 2001 / 5000（事务回滚）

### 2.2.5 删除配方明细
