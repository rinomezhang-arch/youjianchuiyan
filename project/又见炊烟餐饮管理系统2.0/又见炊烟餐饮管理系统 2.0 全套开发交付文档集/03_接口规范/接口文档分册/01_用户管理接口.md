## 通用约定

### 全局请求头

| 请求头 | 必填 | 说明 |
|--------|------|------|
| storeId | 是 | 门店 ID，用于多门店数据隔离；登录接口除外 |
| Authorization | 是 | `Bearer <JWT>`，除登录外所有接口必填 |
| Content-Type | 否 | POST/PUT 请求体为 application/json |

### 全局响应格式

```json
{
  "code": 0,
  "message": "success",
  "data": {}
}
```

- `code = 0` 表示成功，非 0 表示失败
- `data` 为业务数据，可为对象、数组或 null

### 通用错误码

| code | 含义 | 触发场景 |
|------|------|----------|
| 0 | success | 请求成功 |
| 1001 | 参数校验失败 | 必填参数缺失、格式错误 |
| 1002 | 请求体格式错误 | JSON 解析失败 |
| 1003 | 重复数据 | 唯一键冲突 |
| 2001 | 未登录 / Token 失效 | 缺少 Authorization 或 Token 非法 |
| 2002 | Token 过期 | JWT 超时，需重新登录 |
| 3001 | 无操作权限 | 角色无对应权限 |
| 3002 | 越权访问 | 跨门店访问非本店数据 |
| 4001 | 记录不存在 | 主键查询为空 |
| 4002 | 记录已被删除 | 命中逻辑删除标记 |
| 4003 | 状态不允许操作 | 业务状态机非法迁移 |
| 5000 | 业务异常 | BusinessException |
| 9000 | 系统异常 | 未捕获异常 |

### 通用分页参数

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| page | Integer | 否 | 页码，默认 1 |
| size | Integer | 否 | 每页条数，默认 10 |
| keyword | String | 否 | 模糊搜索关键字 |

### 通用分页响应

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "total": 100,
    "page": 1,
    "size": 10,
    "records": []
  }
}
```

## 1.1 StaffController 员工管理

        "staffId": 1001,

- **响应示例**：

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "token": "eyJhbGciOiJIUzI1NiJ9.eyJzdWIi...",
    "tokenType": "Bearer",
    "expiresIn": 86400,
    "userId": 1,
    "username": "admin",
    "staffName": "管理员",
    "roles": ["ROLE_ADMIN"],
    "storeId": 1
  }
}
```

- **错误码**：0 / 1001 / 5000（用户名或密码错误）/ 4003（账号已禁用）

- **路径**：`/api/auth/changePassword`
