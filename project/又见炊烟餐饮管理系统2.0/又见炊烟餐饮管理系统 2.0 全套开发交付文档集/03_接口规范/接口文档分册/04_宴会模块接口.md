## 通用约定

### 全局请求头

| 请求头 | 必填 | 说明 |
|--------|------|------|
| storeId | 是 | 门店 ID，多门店数据隔离 |
| Authorization | 是 | `Bearer <JWT>` |
| Content-Type | 否 | POST/PUT 为 application/json |

### 全局响应格式

```json
{ "code": 0, "message": "success", "data": {} }
```

### 通用错误码

| code | 含义 | 触发场景 |
|------|------|----------|
| 0 | success | 请求成功 |
| 1001 | 参数校验失败 | 必填参数缺失 |
| 1002 | 请求体格式错误 | JSON 解析失败 |
| 1003 | 重复数据 | 模板 / 类型名称重复 |
| 2001 | 未登录 / Token 失效 | 缺少 Authorization |
| 2002 | Token 过期 | JWT 超时 |
| 3001 | 无操作权限 | 角色无权限 |
| 3002 | 越权访问 | 跨门店访问 |
| 4001 | 记录不存在 | 主键查询为空 |
| 4002 | 记录已被删除 | 命中逻辑删除标记 |
| 4003 | 状态不允许操作 | 模板已被预订引用 |
| 5000 | 业务异常 | BusinessException（多表事务回滚） |
| 9000 | 系统异常 | 未捕获异常 |

## 4.1 BanquetTemplateController 宴会模板

- **类映射前缀**：`/banquetTemplate`
- **完整路径示例**：`/api/banquetTemplate/list`
- **说明**：宴会菜单模板，含模板-类型关联；多表事务。

### 4.1.1 模板列表

- **方法**：GET
- **路径**：`/api/banquetTemplate/list`
- **请求头**：storeId、Authorization

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| page | Integer | 否 | 页码，默认 1 |
| size | Integer | 否 | 每页条数，默认 10 |
| typeId | Long | 否 | 宴会类型 ID 过滤 |
| keyword | String | 否 | 模板名称搜索 |

- **响应示例**：

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "total": 18,
    "page": 1,
    "size": 10,
    "records": [
      {
        "templateId": 1,
        "templateName": "标准婚宴 1288 套餐",
        "tablePrice": 1288.00,
        "typeId": 1,
        "typeName": "婚宴",
        "dishCount": 16,
        "storeId": 1
      }
    ]
  }
}
```

- **错误码**：0 / 2001

### 4.1.2 模板详情

- **方法**：GET
- **路径**：`/api/banquetTemplate/{id}`
- **请求头**：storeId、Authorization

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| id | Long | 是 | 模板 ID（路径参数） |

- **响应示例**：

```json
{

  "message": "success",
  "data": {

    "templateName": "标准婚宴 1288 套餐",
    "tablePrice": 1288.00,

    "remark": "含基础酒水",
    "storeId": 1
  }
}
```

- **错误码**：0 / 4001 / 3002

### 4.1.3 新增模板

- **方法**：POST

- **请求头**：storeId、Authorization

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| templateName | String | 是 | 模板名称 |
| tablePrice | BigDecimal | 是 | 每桌价格 |
| minTables | Integer | 否 | 最低桌数 |
| remark | String | 否 | 备注 |
