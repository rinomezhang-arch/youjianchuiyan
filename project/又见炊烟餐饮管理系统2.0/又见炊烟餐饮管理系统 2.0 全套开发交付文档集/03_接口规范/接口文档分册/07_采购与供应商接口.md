# 07 采购与供应商接口分册

| 项目 | 内容 |
|------|------|
| 模块名称 | 采购与供应商 |
| Controller 数量 | 2 |
| 覆盖 Controller | PurchaseController / SupplierController |
| 维护人 | 又见炊烟研发组 |
| 文档版本 | 2.0 |
| 更新日期 | 2026-08-02 |
| 后端端口 | 8080 |
| 网关前缀 | 前端通过 Nginx 反代 /api/* 访问后端 |

---

## 通用约定

### 全局请求头

| 请求头 | 必填 | 说明 |
|--------|------|------|
| storeId | 是 | 门店 ID，多门店数据隔离 |
| Authorization | 是 | `Bearer <JWT>` |
| Content-Type | 否 | POST/PUT 为 application/json |

### 全局响应格式

```json
{ "code": 0, "message": "success", "data": {} }
```

### 通用错误码

| code | 含义 | 触发场景 |
|------|------|----------|
| 0 | success | 请求成功 |
| 1001 | 参数校验失败 | 必填参数缺失 |
| 1002 | 请求体格式错误 | JSON 解析失败 |
| 1003 | 重复数据 | 采购单号 / 供应商编码重复 |
| 2001 | 未登录 / Token 失效 | 缺少 Authorization |
| 2002 | Token 过期 | JWT 超时 |
| 3001 | 无操作权限 | 角色无采购权限 |
| 3002 | 越权访问 | 跨门店访问 |
| 4001 | 记录不存在 | 主键查询为空 |
| 4002 | 记录已被删除 | 命中逻辑删除标记 |
| 4003 | 状态不允许操作 | 采购单已入库不可改 |
| 5000 | 业务异常 | BusinessException |
| 9000 | 系统异常 | 未捕获异常 |

## 7.1 PurchaseController 采购管理

- **类映射前缀**：`/purchase`
- **完整路径示例**：`/api/purchase/list`
- **说明**：采购单与采购明细、审批、到货验收。

### 7.1.1 采购单列表

- **方法**：GET
- **路径**：`/api/purchase/list`
- **请求头**：storeId、Authorization

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| page | Integer | 否 | 页码 |
| size | Integer | 否 | 每页条数 |
| keyword | String | 否 | 单号 / 供应商搜索 |
| status | String | 否 | 状态 |

- **响应示例**：

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "total": 20,
    "page": 1,
    "size": 10,
    "records": [
      {
        "purchaseId": 1,
        "purchaseNo": "CG-2026-0001",
        "supplierId": 301,
        "supplierName": "鲜达食材",
        "purchaseDate": "2026-07-30",
        "totalAmount": 3200.00,
        "status": "待审批",
        "storeId": 1
      }
    ]
  }
}
```

- **错误码**：0 / 2001

### 7.1.2 采购单详情

- **方法**：GET
- **路径**：`/api/purchase/{id}`
- **请求头**：storeId、Authorization

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| id | Long | 是 | 采购单 ID（路径参数） |

- **响应示例**：

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "purchaseId": 1,
    "purchaseNo": "CG-2026-0001",
    "supplierId": 301,
    "supplierName": "鲜达食材",
    "purchaseDate": "2026-07-30",
    "totalAmount": 3200.00,
    "status": "待审批",
    "remark": "周末备货",
    "items": [
      { "itemId": 1, "ingredientId": 201, "ingredientName": "鸡腿肉", "qty": 100.0, "unit": "斤", "unitPrice": 20.00, "amount": 2000.00 }
    ]
  }
}
```

- **错误码**：0 / 4001 / 3002

### 7.1.3 按状态查询

- **请求头**：storeId、Authorization

| 参数名 | 类型 | 必填 | 说明 |

### 7.1.5 新增采购单

- **方法**：POST
- **路径**：`/api/purchase`
- **请求头**：storeId、Authorization

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| supplierId | Long | 是 | 供应商 ID |
| purchaseDate | Date | 是 | 采购日期 |
| items | Array | 是 | 采购明细 |
| items[].ingredientId | Long | 是 | 原料 ID |
| items[].qty | BigDecimal | 是 | 数量 |
| items[].unitPrice | BigDecimal | 是 | 单价 |
| remark | String | 否 | 备注 |

- **响应示例**：

```json
{ "code": 0, "message": "success", "data": { "purchaseId": 2, "purchaseNo": "CG-2026-0002" } }
```

- **错误码**：0 / 1001 / 4001（供应商不存在）/ 5000

### 7.1.6 修改采购单

- **路径**：`/api/purchase/{id}`
- **请求头**：storeId、Authorization

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|

- **响应示例**：

```json

```

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| id | Long | 是 | 采购单 ID（路径参数） |
| approvedBy | String | 否 | 审批人 |

- **响应示例**：

