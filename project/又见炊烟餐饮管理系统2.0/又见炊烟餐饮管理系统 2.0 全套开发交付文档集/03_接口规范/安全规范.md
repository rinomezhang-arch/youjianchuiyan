## 一、认证与授权

### 1.1 JWT Token 安全
```java
// ✅ Token 有效期设置
accessToken:  30分钟
refreshToken: 7天

// ✅ Token 刷新机制
- accessToken 过期前5分钟，前端用 refreshToken 换取新 token
- refreshToken 只能使用一次，使用后自动失效

// ❌ 禁止
- 禁止将密码、手机号等敏感信息写入 token payload
- 禁止在 token 中存储权限列表（应从数据库实时查询）
```

### 1.2 密码安全
```java
// ✅ 密码存储
- 使用 BCrypt 加密，salt rounds >= 10
- 禁止使用 MD5、SHA1 等弱哈希

// ✅ 密码策略
- 最少8位，包含大小写字母+数字
- 连续5次输错密码，锁定账号30分钟
- 密码修改后，旧 token 立即失效
```

### 1.3 门店隔离
```java
// ✅ 数据隔离
- 所有业务查询必须带 store_id 条件
- 使用 StoreDataScopeAspect 切面自动注入 store_id
- 禁止在 SQL 中硬编码 store_id

// ❌ 禁止
- 禁止 A 门店访问 B 门店数据
- 禁止通过修改请求参数越权访问
```

## 二、输入校验

### 2.1 后端校验
```java
// ✅ 必须校验
@NotNull    - 非空校验
```

### 2.2 前端校验
```javascript
// ✅ 必须校验
- 必填项不能为空
- 手机号格式：/^1[3-9]\d{9}$/
- 金额格式：/^\d+(\.\d{1,2})?$/

// ✅ 防重复提交
- 提交按钮点击后立即禁用
- 接口请求加唯一标识（idempotency-key）
```

### 2.3 SQL注入防护
```java
// ✅ 正确做法
@Query("SELECT b FROM BookingMaster b WHERE b.customerPhone = :phone")
List<BookingMaster> findByCustomerPhone(@Param("phone") String phone);

// ❌ 禁止
@Query("SELECT b FROM BookingMaster b WHERE b.customerPhone = '" + phone + "'")
```

## 三、XSS防护

### 3.1 输入过滤
```java
// ✅ 后端过滤
public class XssFilter implements Filter {
    @Override
    public void doFilter(ServletRequest request, ServletResponse response, FilterChain chain) {
        HttpServletRequest httpRequest = (HttpServletRequest) request;
        XssHttpServletRequestWrapper xssRequest = new XssHttpServletRequestWrapper(httpRequest);
        chain.doFilter(xssRequest, response);
    }
}

// ✅ 前端过滤
- 使用 v-html 时必须做 DOMPurify 过滤
- 禁止直接使用 innerHTML
```

### 3.2 输出转义
```java
// ✅ 后端转义
public String escapeHtml(String input) {
    if (input == null) return null;
    return input.replace("&", "&amp;")
                .replace("<", "&lt;")
                .replace(">", "&gt;")
                .replace("\"", "&quot;")
                .replace("'", "&#39;");
}
```

## 五、敏感数据保护

### 5.1 数据脱敏
```java
// ✅ 手机号脱敏：138****8888
public String maskPhone(String phone) {
    if (phone == null || phone.length() != 11) return phone;
    return phone.substring(0, 3) + "****" + phone.substring(7);
}

// ✅ 身份证脱敏：310***********1234
public String maskIdCard(String idCard) {
    if (idCard == null || idCard.length() != 18) return idCard;
    return idCard.substring(0, 3) + "***********" + idCard.substring(14);
}

// ✅ 银行卡脱敏：6222 **** **** 1234
public String maskBankCard(String card) {
    if (card == null) return card;
    return card.replaceAll("(\\d{4})\\d+(\\d{4})", "$1 **** **** $2");
}
```

### 5.2 日志脱敏
```java
// ✅ 日志中禁止出现
- 明文密码
- 完整手机号
- 完整身份证号
- 完整银行卡号
- 支付密码

// ✅ 正确做法
log.info("用户登录, phone=138****8888");
log.info("支付成功, orderId={}, amount={}", orderId, amount);
```

### 5.3 接口脱敏
```java

public class UserVO {
```

## 六、文件上传安全

### 6.1 文件类型校验
```java
// ✅ 白名单校验
private static final Set<String> ALLOWED_TYPES = Set.of(
    "image/jpeg", "image/png", "image/gif",
    "application/pdf",
    "application/vnd.ms-excel",
    "application/vnd.openxmlformats-officedocument.spreadsheetml.sheet"
);

if (!ALLOWED_TYPES.contains(file.getContentType())) {
    throw new BusinessException("文件类型不支持");
}

// ✅ 文件后缀校验
String filename = file.getOriginalFilename();
String suffix = filename.substring(filename.lastIndexOf(".") + 1).toLowerCase();
if (!Set.of("jpg", "jpeg", "png", "gif", "pdf", "xls", "xlsx").contains(suffix)) {
    throw new BusinessException("文件后缀不支持");
}
```

### 6.2 文件大小限制
```yaml
# ✅ application.yml
spring:
  servlet:
    multipart:
      max-file-size: 10MB
      max-request-size: 50MB
```

### 6.3 文件存储安全
```java
// ✅ 重命名文件
String newFilename = UUID.randomUUID() + "." + suffix;

// ✅ 存储路径不能包含用户输入
String path = "/uploads/" + LocalDate.now() + "/" + newFilename;

// ❌ 禁止
String path = "/uploads/" + filename;  // 可能包含 ../../ 等路径穿越
```

## 七、接口安全

### 7.1 限流
```java
// ✅ 接口限流
@RateLimiter(value = 10, timeout = 60)  // 60秒内最多10次
@PostMapping("/api/sms/send")
public Result<Void> sendSms(@RequestBody SmsDTO dto) {
    // ...
}

// ✅ 全局限流
- 单IP每分钟最多60次请求

```

### 7.2 防重放
```java
// ✅ 请求加时间戳
{
    "timestamp": 1690000000000,
    "nonce": "random_string",
    "sign": "signature"
}

// ✅ 后端校验
- timestamp 与服务器时间差不超过5分钟
- nonce 5分钟内不能重复
- sign 签名校验
```

## 八、数据库安全

### 8.1 账号权限
```sql
-- ✅ 最小权限原则
-- 应用账号：只能访问 banquet 数据库
CREATE USER 'banquet_app'@'%' IDENTIFIED BY 'strong_password';
GRANT SELECT, INSERT, UPDATE, DELETE ON banquet.* TO 'banquet_app'@'%';

-- 备份账号：只能执行备份操作
CREATE USER 'banquet_backup'@'%' IDENTIFIED BY 'strong_password';
GRANT SELECT, LOCK TABLES, SHOW VIEW ON banquet.* TO 'banquet_backup'@'%';

-- ❌ 禁止
-- 禁止应用使用 root 账号
-- 禁止授予 DROP、TRUNCATE 等高危权限
```

### 8.2 数据备份
```bash
# ✅ 每日自动备份
0 2 * * * /usr/bin/mysqldump -u banquet_backup -p'xxx' banquet | gzip > /backup/banquet_$(date +\%Y\%m\%d).sql.gz

# ✅ 备份保留策略
- 日备份保留7天
- 周备份保留4周
- 月备份保留12个月
```
