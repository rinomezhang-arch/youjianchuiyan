## 4. 字段约定

### 4.1 通用字段
| 字段名 | 类型 | 说明 |
|--------|------|------|
| `<表>_id` | `INT`/`BIGINT` AUTO_INCREMENT | 主键 |
| `store_id` | `BIGINT NOT NULL` | 多租户隔离字段（强制） |
| `created_at` | `DATETIME DEFAULT CURRENT_TIMESTAMP` | 创建时间 |
| `updated_at` | `DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP` | 更新时间 |
| `is_active` | `TINYINT DEFAULT 1` | 启用标志（1=启用 0=停用） |
| `remark` | `VARCHAR(500)` | 备注 |

### 4.2 类型规范
| 业务含义 | 推荐类型 |
|---------|---------|
| 金额 | `DECIMAL(12,2)`，禁止 FLOAT/DOUBLE |
| 比例/百分比 | `DECIMAL(10,2)` |
| 数量 | `DECIMAL(10,2)`（支持小数如 0.5 斤） |
| 编码 | `VARCHAR(50)` |
| 名称 | `VARCHAR(100)` |
| 状态 | `VARCHAR(20)` 字典编码 或 `TINYINT` |
| 手机号 | `VARCHAR(20)`（支持国际号） |
| 长文本 | `TEXT` |

## 5. 索引规范

- **主键**：所有表必须有 `AUTO_INCREMENT` 整型主键
- **唯一索引**：业务编码（如 `uk_booking_id` / `uk_role_code` / `uk_dict_code`）
- **复合索引**：覆盖 `store_id` + 业务字段（如 `idx_store_phone`、`uk_role_perm`）
- **外键索引**：所有外键字段建议加索引

## 6. 约束规范

- **NOT NULL**：业务必填字段强制 NOT NULL
- **DEFAULT**：状态类字段给默认值（如 `is_active DEFAULT 1`）
- **UNIQUE**：业务唯一性约束（如 `(store_id, customer_name, customer_phone)`）
- **FOREIGN KEY**：仅在关键关联表使用，注意被引用表必须有 UNIQUE 索引

## 7. 多租户隔离规则

1. **强制字段**：所有业务表必须有 `store_id` 字段
2. **查询过滤**：所有 SELECT 必须带 `WHERE store_id=?`
3. **写入隔离**：店长（非 GM）写入强制使用 `UserContext.getCurrentStoreId()`，防止伪造 storeId
4. **跨店访问**：仅 GM 角色 `data_scope=all` 可跨门店查询/写入
5. **0=全局**：`store_id=0` 表示全局共享数据（如字典、配置默认值）
