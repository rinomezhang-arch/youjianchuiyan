**状态**: 前端Assets.vue只管固定资产，工具/个人资产没有！

#### 固定资产 vs 工具资产

| 维度 | 固定资产(财务管) | 工具资产(部门管) |
|------|-----------------|-----------------|
| 价值 | 高(>2000元) | 低(<2000元) |
| 折旧 | 要折旧 | 不折旧 |
| 使用人 | 公共 | 个人领用 |
| 盘点 | 年度 | 月度/季度 |
| 例子 | 冰箱、空调、桌椅 | 刀具、锅具、托盘、工具箱 |

| `tool_issue` | 领用记录 | issue_id, staff_id, tool_id, qty, issue_date, return_date, status | staff_id → staff_master, tool_id → tool_master |
| `tool_return` | 归还记录 | return_id, issue_id, return_date, condition(完好/损坏/丢失) | issue_id → tool_issue |

