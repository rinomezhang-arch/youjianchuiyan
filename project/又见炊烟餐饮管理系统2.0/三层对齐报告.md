## 三、需要修复的问题（按优先级）

### P0 - 前端路径错误（调不通后端）

1. **FrontDesk.vue** → `/api/front-desk/*` 全部要改成 `/api/tables`、`/api/bookings` 等
2. **PriceTiers.vue** → `/api/price-tiers` 改成 `/api/member-levels`
3. **StockTake.vue** → `/api/inventory/stock-take` 改成 `/api/stock-takes`
4. **Receipt.vue** → `/api/inventory/receipts` 改成 `/procurement/receipts`
5. **Approval.vue** → `/api/approvals` 改成 `/api/approval`
6. **StoreOrg.vue** → `/api/departments` 改成 `/api/hr/departments`
7. **MenuManager/MenuHub/MenuAlacarte** → `/menu/*` 改成 `/api/dishes/*`

### P1 - 后端缺Controller/端点

1. **SysNotification** — 有表无API，前端通知功能无支撑
2. **HR Self-Service** — ReviewQueue/SelfService调用的 `/api/hr/self-service/*` 不存在
3. **Guest Analysis** — 前端GuestAnalysis.vue无对应后端Controller
4. **Supplier Reconciliation** — 前端有页面但后端无专门Controller
5. **Dashboard** — 需确认子路径（overview/today-bookings/revenue-chart等）是否实现

### P2 - 后端缺数据库表

1. **marketing系列** — 活动/优惠券/签到/分享等API无对应表
2. **energy系列** — 能耗记录无表
3. **engineering系列** — 巡检/工单/备件无表
4. **maintenance系列** — 资产/维修请求无表
5. **member_levels** — 会员等级无表
