## 3. 表与字段铁律

### 3.1 COMMENT必须
每个字段必须有 `COMMENT '中文注释'`。检测方法:
```sql
SELECT TABLE_NAME, COUNT(*) AS total, SUM(CASE WHEN COLUMN_COMMENT!='' THEN 1 ELSE 0 END) AS commented
FROM information_schema.COLUMNS WHERE TABLE_SCHEMA='banquet'
GROUP BY TABLE_NAME HAVING total != commented;
```
结果必须为空。

### 3.2 计算列公式（不准手填）
| 表 | 计算列 | 公式 |
|----|--------|------|
| ingredient_cost_price | net_price_per_unit | purchase_price / conversion_rate / (yield_rate/100) |
| purchase_order_detail | amount | quantity × unit_price |
| purchase_receipt_detail | amount | actual_quantity × unit_price |
| purchase_order | total_quantity | SUM(purchase_order_detail.quantity) |
| purchase_order | total_amount | SUM(purchase_order_detail.amount) |
| purchase_receipt | total_quantity | SUM(purchase_receipt_detail.actual_quantity) |
| dish_recipe | unit_price | 查 ingredient_cost_price.net_price_per_unit |
| dish_recipe | total_cost | quantity × unit_price |
| dish_recipe | wastage_rate | 100 - yield_rate |
| dish_cost_card | standard_cost | SUM(dish_recipe.total_cost) |
| dish_master | cost_price | 查 dish_cost_card.standard_cost |
| dish_master | cost_rate | cost_price / sale_price × 100 |

### 3.3 单位换算
从 `unit_conversion` 表查，常见值:
斤→克=500  公斤→克=1000  箱→克=按规格  瓶→克=按容量  只→克=按单重

### 3.4 出成率
- 畜肉类80-95%  禽类70-85%  水产65-80%  蔬菜80-90%
- 调味品/粮油/酒水=100%

## 4. 数据流铁律（不可跳过）

```
供应商 → 采购申请 → 审批 → 验收 → 入库 → 成本换算 → 出成率 → 配方 → 成本卡 → 菜品入库
```

跳过任何一环，后续数据全部作废。

```bash
SELECT 'net_price 100%' AS chk, SUM(CASE WHEN ABS(ROUND(purchase_price/conversion_rate/(yield_rate/100),8)-net_price_per_unit)<0.000001 THEN 1 ELSE 0 END) AS ok, COUNT(*) AS total FROM banquet.ingredient_cost_price WHERE store_id=1;
SELECT 'amount 100%' AS chk, SUM(CASE WHEN ABS(ROUND(quantity*unit_price,2)-amount)<0.01 THEN 1 ELSE 0 END) AS ok, COUNT(*) AS total FROM banquet.purchase_order_detail WHERE store_id=1;
SELECT 'cost_price回填100%' AS chk, SUM(CASE WHEN ABS(dm.cost_price-cc.standard_cost)<0.01 THEN 1 ELSE 0 END) AS ok, COUNT(*) AS total FROM banquet.dish_master dm JOIN banquet.dish_cost_card cc ON dm.dish_id=cc.dish_id;
SELECT 'supplier NULL' AS chk, COUNT(*) AS cnt FROM banquet.ingredient_master WHERE store_id=1 AND primary_supplier_id IS NULL;
"
```

所有指标必须100%。
