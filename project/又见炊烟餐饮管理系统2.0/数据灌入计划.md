## 🚨 铁律：数据必须经过以下完整流程才能合法入库

```
Excel源文件（宴会成本菜单录入表.xlsm）
  ├── 菜肴信息表（348道菜）
  ├── 成本信息表（1217个原料+单价）
  └── 模板Sheet（菜品配料表格式）

         ↓ 反推

[步骤1] → [步骤2] → [步骤3] → [步骤4] → [步骤5] → [步骤6] → [步骤7]

供应商 → 申请采购 → 审批通过 → 到货验收 → 入库 → 成本换算 → 出成率 → 菜品配方 → 成本卡 → 菜肴主表
                                                                                        ↓
                                                                                  菜品入库完成
```

**禁止：跳过任何中间步骤直接往 dish_master 或 dish_recipe 灌数据。没有采购就没有原料，没有原料就没有成本，没有成本就不能入菜品。**

### 3.2 关键字段：conversion_rate（换算率）
**每种非"克"单位的原料必须提供换算率：**
- 瓶 → 克：根据容量（500ml≈500g, 1.25L≈1250g…）
- 个 → 克：根据单个重量（鸡蛋≈50g, 皮蛋≈60g, 鸽子≈300g…）
- 只 → 克：根据单只重量（乳鸽≈300g, 水晶鸡≈1000g…）
- 袋 → 克：根据包装重量（500g/袋, 1000g/袋…）
- 盒 → 克：根据盒装重量
- 桶 → 克：2.5L≈2500g
- 条 → 克：辽参≈50g/条
- 板 → 克：豆腐≈3000g/板
- 块 → 克：蛋卷≈20g/块, 鸭血≈300g/块
- 包 → 克：龙口粉丝≈200g/包

**conversion_rate 必须合理，并有注释说明换算依据。**

## 步骤5：入库 → ingredient_purchase + ingredient_cost_price + unit_conversion

**这是核心换算层，必须计算正确。**

### 5.1 表：ingredient_purchase（采购入库记录）
| 字段 | 必须填 | 说明 |
|------|--------|------|
| store_id | 1或2 | |
| ingredient_id | FK→ingredient_master | |
| supplier_id | FK→supplier_master | |
| purchase_date | 入库日期 | |
| purchase_quantity | **>0** | 采购数量（采购单位） |
| purchase_price | **>0** | 采购单价（元/采购单位） |
| purchase_total | purchase_quantity × purchase_price | |
| usage_quantity | 换算后的使用数量 | 后补 |
| usage_price | 换算后的使用单价 | 后补 |

**注意：purchase_quantity/purchase_price/purchase_total 用采购单位（箱/斤/瓶），usage_quantity/usage_price 用使用单位（克）。两者都要填。**

### 5.2 表：ingredient_cost_price（成本换算表）
每一行是从采购单位到使用单位的换算结果。

| 字段 | 值 | 说明 |
|------|-----|------|
| ingredient_id | FK→ingredient_master | |
| ingredient_name | 原料名称 | |
| purchase_unit | 采购单位 | 斤/箱/瓶/个 |
| purchase_price | 采购单价（元/采购单位） | |
| conversion_unit | 转换后单位 | 绝大多数是"克" |
| conversion_rate | 换算率 | 从ingredient_master取 |
| yield_rate | 出成率 | 从yield_rate_config取（先填100） |
| net_price_per_unit | **= purchase_price ÷ conversion_rate ÷ (yield_rate/100)** | **核心公式** |

**net_price_per_unit 的计算公式：**
```
net_price_per_unit = purchase_price / conversion_rate / (yield_rate / 100)
```
例如：五花肉 20元/斤，1斤=500g，出成率85%
→ net_price_per_unit = 20 / 500 / 0.85 = 0.0471 元/克

### 5.3 表：unit_conversion（单位换算表）
通用换算规则，所有非"克"单位都需要一条记录：

| 字段 | 值 |
|------|-----|
| from_unit | 采购单位 |
| to_unit | 克 |
| conversion_rate | 换算倍率 |
| category | 重量/容量/数量 |

**常用换算：**
- 斤 → 克：500
- 公斤 → 克：1000
- 箱 → 克：按规格（如1×12×350ml=4200ml≈4200g）
- 瓶 → 克：按容量（500ml≈500g）
- 个/只 → 克：按单重
- 桶 → 克：按容量
- 毫升 → 克：1（水和多数液体近似）

| 字段 | 值 | 说明 |

### 6.2 出成率参考标准（餐饮行业通用）

| 类别 | 典型出成率 |
|------|-----------|
| 畜肉类（五花肉/牛肉/排骨） | 80-90% |

**出成率必须合理，不能全是100%。调味品/粮油/酒水可以100%，肉禽水产必须有损耗。**

## 步骤7：菜品配方 → dish_recipe + dish_cost_card + dish_master

**最后一步，必须在前面所有步骤完成之后。**

### 7.1 表：dish_master（菜品主表）
从Excel"菜肴信息表"灌入348道菜。

| 字段 | 来源 |
|------|------|
| dish_id | CY000001-CY000423（保持Excel原编码） |
| dish_name | 菜肴名称 |
| dish_category | 菜肴类别 |
| spicy_level | 辣度 |
| main_ingredient_type | 主料类别 |
| main_ingredient | 主料 |
| english_name | 英文翻译 |
| cost_price | 从dish_cost_card汇总计算 |
| sale_price | 售价 |
| cost_rate | cost_price / sale_price |
| cooking_time | 出菜时长 |
| menu_type | 根据类别映射（alacarte/banquet） |
| is_active | 1 |
| 节日名称列 | 生日/婚宴/乔迁…直接从Excel对应列灌 |

### 7.2 表：dish_recipe（菜品配方表）
**这是最复杂的部分。每道菜的配方从Excel模板Sheet反推。**

每道菜需要列出：
- 用了哪些原料（ingredient_id → FK→ingredient_master）
- 每种原料用了多少（quantity，单位克）
- 每种原料的成本单价（unit_price，从ingredient_cost_price.net_price_per_unit取）
- 每种原料的出成率（yield_rate，从yield_rate_config取）
- 损耗率（wastage_rate = 100 - yield_rate）

**total_cost = quantity × unit_price（已经考虑了出成率的净价）**

### 7.3 表：dish_cost_card（成本卡）
**每道菜一张成本卡。**

| 字段 | 来源 |
|------|------|
| dish_id | FK→dish_master |
| dish_name | 菜名 |
| standard_yield | 标准出成率 |
| standard_cost | = SUM(dish_recipe.total_cost) 所有原料合计 |
| actual_cost | 同standard_cost（实际成本暂无差异） |
| selling_price | 售价 |
| gross_margin | (售价-成本)/售价×100 |

### 7.4 表：dish_cost_card_detail（成本卡明细）
每条对应 dish_recipe 的一条，汇总到 cost_card_id。

## 执行顺序铁律

```
1. 清理假数据（步骤0）
2. dish_category + dish_tag（建立分类标签）
3. supplier_master（补全供应商）
4. ingredient_master（建1217个原料档案，含换算率）  ← 关键
5. purchase_order + purchase_order_detail（按类别分批采购）
6. purchase_receipt + purchase_receipt_detail（到货验收）
7. ingredient_purchase（入库记录）
8. yield_rate_config（出成率配置）
9. ingredient_cost_price（成本换算）  ← 关键公式
10. unit_conversion（单位换算表）
11. dish_master（348道菜入库）
12. dish_recipe（每道菜配方）
13. dish_cost_card + dish_cost_card_detail（成本卡汇总）
14. inventory_summary（库存汇总更新）
```

3. **所有表和字段必须有中文COMMENT注释**
4. **每个步骤执行后必须验证**（SELECT COUNT(*) + 抽查）
