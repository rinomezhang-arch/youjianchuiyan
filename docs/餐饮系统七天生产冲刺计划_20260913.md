# 又见炊烟餐饮系统七天生产冲刺计划

目标：在同一候选提交和同一制品上，把餐饮业务的实体、接口、页面、数据库关系、打印报表与真实操作闭环验证到可发布状态。法务模块、诉讼数据、法务配置和张律师既有权限全程冻结。

## 执行规则

- COS 任务板是任务归属与状态唯一事实源；每人同时只做一张主卡，完成或阻断后立即续接。
- 固定分工：Codex 设计场景、数据结构、验收与集成；Trae 做批量构建、合并、发布包和耗时 E2E；Claude 有额度时只做复杂业务与关键复核；天龙做后端、迁移和数据门禁；地龙做窄范围独立黑盒验收。
- 每次返工只补验收指出的缺口，复用仍有效证据；禁止重新全盘扫描、反复构建和无边界试错。
- `started` 必须对应实际执行，`reported` 必须带提交和原始证据；编译、HTTP 200、空列表和口头完成不算通过。
- 额度告警前必须提交、上板、写交接并通知 `codex/current`；不允许任务停在假 claimed 状态。
