# 宴会预订场景设计文档

> 微龙整理 | 2026-07-31

## 一、概述

又见炊烟餐饮管理系统的核心业务场景，覆盖5类宴会预订场景。

## 二、场景清单

### 1. 商务宴请

| 维度 | 说明 |
|------|------|
| 用餐时段 | 午餐 11:30-13:30 / 晚餐 17:00-21:00 |
| 桌型偏好 | 包间优先（300/400/500 包间） |
| 人数规模 | 8-20 人 |
| 套餐选择 | 迎春接福宴（1188元）或客制菜单 |
| 关键需求 | 私密空间、上菜节奏控制、酒水服务 |
| 散座要求 | 极少用散座，一般不接受大厅 |

**流程**：
1. 客户电话/到店 → 前台查询可用包间
2. 选择套餐或定制菜品
3. 确认人数、时间、菜单
4. 支付订金（可微信/支付宝）
5. 提前2小时确认桌位布置
6. 当天客户到店 → 引导入座 → 上菜

### 2. 婚宴

| 维度 | 说明 |
|------|------|
| 用餐时段 | 午餐 10:00-13:30 / 晚餐 17:00-21:00 |
| 桌型偏好 | 宴会厅（扶摇厅为主） |
| 人数规模 | 20-50桌（每桌10人） |
| 套餐选择 | 百年好合宴（1288元）或客制菜单 |
| 关键需求 | 场地布置（红毯/背景板）、音响设备、婚庆协调 |
| 散座要求 | 不适用，必须独立场地 |

**流程**：
1. 客户预约看场地 → 确认档期可用
2. 确认桌数、菜品、布置方案
3. 签署合同、支付订金
4. 婚庆布置入场（提前1-2天）
5. 当天：迎宾签到 → 仪式 → 敬酒 → 散席
6. 尾款结算

### 3. 寿宴

| 维度 | 说明 |
|------|------|
| 用餐时段 | 午餐 11:30-13:30 |
| 桌型偏好 | 大包间（500包间）或小宴会厅 |
| 人数规模 | 5-10桌 |
| 套餐选择 | 生日祝寿宴（1588元） |
| 关键需求 | 寿桃/寿面、长寿装饰、长辈照顾 |

**流程**：
1. 提前7天预订
2. 确认菜单（避免长辈忌口）
3. 场地布置（寿字、寿桃装饰）
4. 当天提前到场 → 祝寿环节 → 用餐

### 4. 满月宴

| 维度 | 说明 |
|------|------|
| 用餐时段 | 午餐 11:30-13:30 |
| 桌型偏好 | 中包间（400包间）或小厅 |
| 人数规模 | 3-6桌 |
| 套餐选择 | 客制菜单（偏清淡） |
| 关键需求 | 宝宝座椅、温馨布置、赠品（红蛋） |

**流程**：
1. 提前3-5天预订
2. 确认菜单（亲友口味）
3. 简单布置（气球、满月装饰）
4. 当天赠送红蛋

### 5. 谢师宴

| 维度 | 说明 |
|------|------|
| 用餐时段 | 晚餐 17:00-21:00（暑假6-8月旺季） |
| 桌型偏好 | 大包间或扶摇厅 |
| 人数规模 | 15-30人 |
| 套餐选择 | 迎春接福宴（1188元）或客制菜单 |
| 关键需求 | 老师上座礼仪、致词环节、甜品/果盘 |

**流程**：
1. 提前1-2周预订（旺季需提前锁定档期）
2. 确认人数、主桌安排
3. 准备致词环节（麦克风）
4. 当天：学生接老师 → 致辞 → 敬酒 → 合影

## 三、跨场景通用需求

| 需求 | 实现方式 |
|------|---------|
| 订金管理 | 系统中录入订金金额 + 支付方式，自动关联订单 |
| 桌位查询 | 按日期+时间段查询可用包间/宴会厅/散座 |
| 菜单定制 | 套餐作基础，支持加减菜品、换菜 |
| 价格调整 | 支持整单折扣、单品折扣、免零头 |
| 签单挂账 | 机关单位/老客户支持签单，月末结算 |
| 翻台管理 | 午宴翻台时间管理，避免冲突 |
