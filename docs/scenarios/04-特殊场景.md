# 特殊用餐场景设计文档

> 微龙整理 | 2026-07-31

## 一、概述

非主流程的特殊用餐场景，包括包间管理、散座、外卖、团体预订等。

## 二、场景清单

### 1. 包间用餐

#### 包间分级

| 级别 | 桌数 | 容纳人数 | 最低消费 | 门牌 |
|------|------|---------|---------|------|
| 小包间 | 1桌 | 6-8人 | 300元 | 201/202/203 |
| 中包间 | 1-2桌 | 8-16人 | 500元 | 301/302 |
| 大包间 | 2-3桌 | 16-30人 | 800元 | 501/502 |
| 豪华包间 | 1桌 | 10-14人 | 1000元 | 601 |

#### 包间预订流程
1. 客户电话/到店 → 查询可用包间
2. 选择包间级别 → 确认时间段
3. 收订金（100-500元按级别）
4. 提前1天确认 → 确认人数、菜单
5. 到店 → 引导入包间 → 专属服务员

#### 包间服务标准
- 每个包间配1名专属服务员
- 包间内设呼叫铃
- 包间优先出菜
- 包间支持签单挂账

### 2. 散座用餐

| 维度 | 说明 |
|------|------|
| 位置 | 大厅、露台（夏季） |
| 桌型 | 4人方桌、6-8人圆桌 |
| 最低消费 | 无 |
| 翻台率 | 午1.5轮/晚2轮 |
| 等待排队 | 高峰期需等位（系统叫号） |

**散座管理要点**：
- 到店先问"几位"→ 引导合适桌位
- 高峰期启用等位系统
- 散座不支持签单（现金/扫码结算）

### 3. 外卖/外带

| 维度 | 说明 |
|------|------|
| 渠道 | 电话、微信、美团、饿了么 |
| 营业时间 | 午11:00-13:30 / 晚17:00-20:30 |
| 出餐标准 | 下单后15-30分钟 |
| 包装费 | 2-5元/餐盒 |

**外卖流程**：
1. 接单（平台自动/电话人工）
2. 厨房制作 → 打包
3. 骑手取餐或客户自取
4. 确认收餐 → 扣库存

**注意事项**：
- 部分菜品不支持外卖（汤类、铁板类）
- 外卖不参与宴会套餐折扣
- 需单独录入外卖平台订单编号

### 4. 团体用餐（非宴会】

| 维度 | 说明 |
|------|------|
| 场景 | 单位团建、同学聚会、旅游团餐 |
| 人数 | 20-50人 |
| 桌型 | 大厅拼桌、扶摇厅分区 |
| 结算 | 统一结算或AA |

**区别宴会**：
- 不走宴会预订系统
- 不需要布置/仪式
- 菜品走零点或团体套餐
- 结算走散客流程

### 5. 月结签单（机关单位/企业）

| 维度 | 说明 |
|------|------|
| 适用对象 | 长期合作机关单位、企业 |
| 签单权限 | 授权人签字有效 |
| 结算周期 | 月结（每月15日出账单） |
| 额度限制 | 按单位设置信用额度 |

**签单流程**：
1. 客户到店 → 点菜 → 用餐
2. 结账时出示签单卡
3. 授权人签字确认
4. 前台录签单记录
5. 月末出账单 → 对账 → 付款

### 6. 时令/季节性场景

| 场景 | 季节 | 特殊需求 |
|------|------|---------|
| 年夜饭 | 除夕 | 提前30天预订、特别菜单、分批用餐 |
| 中秋团圆宴 | 中秋 | 月饼赠品、赏月露天座 |
| 谢师宴 | 6-8月 | 暑假旺季、需提前锁定|
| 年夜饭预订 | 12月-1月 | 定额订金、不可退 |
| 龙虾季 | 5-10月 | 小龙虾专柜、啤酒套餐 |

## 三、跨场景系统功能需求

| 功能 | 说明 |
|------|------|
| 等位排队 | 高峰期散座等位叫号 |
| 包间状态看板 | 实时显示包间占用/空闲 |
| 签单管理 | 签单额度、对账、催缴 |
| 外卖对接 | 接美团/饿了么订单并写入系统 |
| 时段定价 | 午餐/晚餐差异化计费 |
| 桌台合并 | 支持多散座拼桌 |
| 促销活动 | 时段特价、会员日折扣 |
