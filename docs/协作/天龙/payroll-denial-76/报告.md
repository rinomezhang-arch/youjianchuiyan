## 三、根因（一次明确诊断，不猜）
失败点**不是产品行为**：`body.contains("403")` 已通过，失败的是中文字面量断言。
`MockHttpServletResponse#getContentAsString()` 在响应未声明字符集时按 **ISO-8859-1** 解码，
而 Controller 的 `Result` 中文消息以 UTF-8 字节落盘，取出即乱码（证据里可见 `æ\x97\xa0æ...`），
故 `contains("无权访问薪酬数据")` 恒为 false。
拦截器路径之所以此前通过，是因为 `ApprovalAuthorityInterceptor#reject` 显式 `setCharacterEncoding("UTF-8")`。
**下一轮修法（测试侧 1 行）**：改取 `response.getContentAsString(StandardCharsets.UTF_8)`（或断言 code 而不比中文字面量）。
