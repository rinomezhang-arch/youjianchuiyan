## 退回项一：转单成功后单号会跟着卡片一起消失

第一轮我把「转换成功后该咨询从待办列表消失」当成优点写进了报告——
**避免诱使重复点击这个理由本身没错，但我漏了后果**：单号是显示在卡片内的，
卡片一消失，员工刚拿到的正式预订单号就没了，还没来得及记。
这是我自己在浏览器里亲眼看到卡片数从 2 变 1、却没意识到问题的地方。

改法：把转单结果（单号 + 是 converted 还是 replayed）持久显示在**卡片之外**的成交记录区，
刷新列表不清除。同一会话内多次转单累积显示，员工随时能回看。
