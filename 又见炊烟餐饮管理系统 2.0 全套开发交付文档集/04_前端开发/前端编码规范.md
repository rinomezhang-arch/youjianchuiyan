## 1. 文件组织

### 1.1 目录结构
```
frontend_v3/
├── src/
│   ├── api/              # 接口请求封装（按模块分文件）
│   ├── assets/           # 静态资源（图片/字体）
│   ├── components/        # 全局公共组件
│   ├── composables/      # 组合式函数（hooks）
│   ├── layout/           # 布局组件
│   ├── router/           # 路由配置
│   ├── store/            # Pinia 状态管理
│   ├── style/            # 全局样式
│   ├── utils/            # 工具函数
│   └── views/            # 页面组件（按模块分目录）
└── vite.config.js
```

### 1.2 文件命名
- **组件文件**：`PascalCase.vue`（如 `Bookings.vue`、`SetMenuEdit.vue`）
- **JS/TS 文件**：`kebab-case.js`（如 `request.js`、`rules.js`）
- **样式文件**：`kebab-case.css`
- **目录**：`kebab-case`

### 1.3 组件命名
- 单文件组件：`PascalCase`（`<Bookings />`）
- 模板内使用：`<bookings />` 或 `<Bookings />` 都可

## 2. Vue 3 组合式 API

### 2.1 `<script setup>` 优先

```vue
<script setup>
import { ref, reactive, computed, onMounted } from 'vue'
import { ElMessage } from 'element-plus'
import { useUserStore } from '@/store/user'

const userStore = useUserStore()
const formRef = ref(null)
const formData = reactive({ name: '', phone: '' })

const isValid = computed(() => formData.name && formData.phone)

onMounted(() => {
  loadData()
})

const loadData = async () => { /* ... */ }
const onSubmit = async () => { /* ... */ }
</script>
```

### 2.2 响应式选择
- **基础类型**：`ref`
- **对象/数组**：`reactive` 或 `ref([])`
- **派生值**：`computed`
- **监听**：`watch` / `watchEffect`

### 2.3 Props 与 Emits

```vue
<script setup>
const props = defineProps({
  modelValue: { type: Boolean, default: false },
  title: { type: String, default: '' }
})
const emit = defineEmits(['update:modelValue', 'success'])

const close = () => emit('update:modelValue', false)
</script>
```

### 2.4 computed 中使用其他 computed

```js
const totalPrice = computed(() => formData.price * formData.quantity)
const formattedPrice = computed(() => `¥${totalPrice.value.toFixed(2)}`)
//                                                ↑ 必须加 .value
```

**陷阱**：`<script setup>` 中 computed 引用另一个 computed 必须加 `.value`，否则数据为空。

## 3. API 请求

### 3.1 统一封装

`utils/request.js`：
```js
import axios from 'axios'
import { ElMessage } from 'element-plus'
import router from '@/router'

const service = axios.create({
  baseURL: '/api',
  timeout: 30000
})

service.interceptors.request.use(config => {
  const token = localStorage.getItem('token')
  if (token) config.headers.Authorization = `Bearer ${token}`
  // 必带 storeId
  if (!config.params) config.params = {}
  if (!config.params.storeId) {
    config.params.storeId = localStorage.getItem('storeId') || 1
  }
  return config
})

service.interceptors.response.use(
  response => {
    const res = response.data
    if (res.code !== 200) {
      ElMessage.error(res.message || '请求失败')
      if (res.code === 401) router.push('/login')
      return Promise.reject(res)
    }
    return res
  },
  error => {
    ElMessage.error(error.message || '网络错误')
    return Promise.reject(error)
  }
)

export default service
```

### 3.2 模块化接口

`api/customer.js`：
```js
import request from '@/utils/request'

export const getCustomers = (params) => request.get('/customers', { params })
export const createCustomer = (data) => request.post('/customers', data)
export const updateCustomer = (id, data) => request.put(`/customers/${id}`, data)
export const deleteCustomer = (id) => request.delete(`/customers/${id}`)
```

页面使用：
```js
import { getCustomers, createCustomer } from '@/api/customer'
```

### 3.3 必带 storeId
**所有 HTTP 请求必须带 `storeId`**，否则后端返回 400 错误。已在 `request.js` 拦截器统一处理。

```js
      // 从 localStorage 恢复 + 拉取用户信息
    },
    async login(credentials) { /* ... */ },

  }
})
```

## 5. 样式规范

### 5.1 全局样式
- 文件位置：`src/style/` 下
- 主色：深绿 `#1a3a2a` + 暗金 `#C4A35A` + 暖米 `#F5F0E8`
- 字体：字酷堂字体（项目专用）
- 字号：基础 14px，标题递增

### 5.2 组件样式
- 使用 `<style scoped>` 隔离
- 不使用 `!important`（除非覆盖第三方样式）
- BEM 命名或 kebab-case

### 5.3 设计规范（用户偏好）
- **布局**：宽页布局，模块横向排列，换行时对称
- **配色**：徽派雅致（深绿+暗金），禁用大红大紫
- **圆角**：弹窗 16px，按钮 4px
- **弹窗**：宽度 50vw（PC）/ 90vw（移动）
- **输入框**：高度 32px，紧凑宽度
- **按钮组**：居中
- **选中态**：金色边框 + 突出
- **图标**：禁用 emoji，用文字标签
- **创建时间**：单行显示

### 5.4 响应式
- 移动端：原生 `<input>` / `<select>` + 底部滑动 drawer
- iPad：触控优化，大按钮，拖拽支持
- PC：完整 el-* 组件

## 8. 常见陷阱

### 8.1 camelCase vs snake_case
后端可能返回 `dishId` 或 `dish_id`，前端 map 时**两种 key 都要支持**：
```js
const img = dishImgMap[dish.dishId] || dishImgMap[dish.dish_id]
```

### 8.2 localStorage 中文字符
浏览器 MCP 工具输入中文会编码错乱，**直接浏览器输入**才正确。

### 8.3 computed.value
`<script setup>` 中 computed 引用必须加 `.value`（除模板中）。

### 8.4 异步组件加载
```js
// ❌ 错误
import Comp from '@/views/Comp.vue'

// ✅ 正确（懒加载）
const Comp = () => import('@/views/Comp.vue')
```
