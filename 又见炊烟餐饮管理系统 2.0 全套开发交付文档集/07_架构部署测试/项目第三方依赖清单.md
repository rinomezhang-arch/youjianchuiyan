## 4. 第三方服务依赖

### 4.1 腾讯云 COS
- **用途**：文件存储 + 备份
- **凭据**：`~/.cos.conf`（INI 格式）
- **Bucket**：`youjian-data-1409286104`，region `ap-nanjing`
- **上传脚本**：`scripts/backup/cos_upload.py`
- **工作空间**：`ai公共工作空间/项目管理/餐饮管理系统/`

### 4.2 短信服务（待接入）
- **候选**：阿里云短信 / 腾讯云短信
- **用途**：预订确认、取消通知、客户回访
- **状态**：NotifyConsumer 中留 TODO，未实现

### 4.3 抖音/百度（菜品推荐链接）
- **用途**：IpadMenu.vue 菜品详情页提供搜索链接
- **接入方式**：URL 跳转（无需 API key）
- **示例**：
  ```js
  // 菜品名搜索抖音
  const douyinUrl = `https://www.douyin.com/search/${encodeURIComponent(dishName)}`
  // 菜品名搜索百度
  const baiduUrl = `https://www.baidu.com/s?wd=${encodeURIComponent(dishName)}`
  ```

## 10. 离线部署

如需离线部署：
1. 在有网环境打包镜像：`docker compose build`
2. 导出镜像：`docker save youjian-backend:latest -o backend.tar`
3. 传输到目标服务器
4. 导入镜像：`docker load -i backend.tar`
5. 启动：`docker compose up -d`
