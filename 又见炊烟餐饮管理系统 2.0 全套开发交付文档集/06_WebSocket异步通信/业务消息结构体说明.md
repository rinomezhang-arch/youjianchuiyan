## 1. 消息整体结构

`NotifyEvent` 类（实现 `Serializable`，跨进程序列化）：

```json
{
  "eventType": "order.created",
  "storeId": 1,
  "title": "新订单 ORD20260802001",
  "content": "桌台 A06 5 道菜",
  "priority": "normal",
  "senderId": 5,
  "senderName": "张三",
  "receiverType": "all",
  "receiverIds": null,
  "relatedType": "booking",
  "relatedId": 12345,
  "triggerTime": "2026-08-02 14:30:00",
  "remark": "客户备注：少辣"
}
```

### 1.1 字段说明

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `eventType` | String | ✅ | 事件类型，见第 2 节 |
| `storeId` | Long | ✅ | 0=全局，1=宁国店，2=宣城店 |
| `title` | String | ✅ | 通知标题（≤200 字符） |
| `content` | String | 否 | 通知内容（可长文本） |
| `priority` | String | 否 | low / normal / high / urgent，默认 normal |
| `senderId` | Integer | 否 | 发送者员工ID |
| `senderName` | String | 否 | 发送者姓名 |
| `receiverType` | String | 否 | all / role / staff / dept，默认 all |
| `receiverIds` | String | 否 | 接收者ID列表（逗号分隔），null=全体 |
| `relatedType` | String | 否 | 关联业务类型：booking / order / purchase 等 |
| `relatedId` | Long | 否 | 关联业务ID |
| `triggerTime` | LocalDateTime | 否 | 触发时间 |
| `remark` | String | 否 | 业务备注 |

## 2. 事件类型常量

`NotifyEvent.NotifyType` 内部类：

| 常量 | 值 | 触发时机 | 推送目标 |
|------|---|---------|---------|
| `ORDER_CREATED` | `order.created` | 下单成功 | KDS 厨房屏 / 前台看板 |
| `DISH_SERVED` | `dish.served` | 菜品出品完成 | 前台看板 / 服务员 |
| `BOOKING_CREATED` | `booking.created` | 预订创建 | 前台 / 桌台看板 |
| `BOOKING_CANCELLED` | `booking.cancelled` | 预订取消 | 桌台看板 / 客户短信 |
| `BOOKING_CONFIRMED` | `booking.confirmed` | 预订确认 | 客户短信 / 店长 |
| `INVENTORY_LOW_STOCK` | `inventory.low_stock` | 库存低于阈值 | 采购员 / 店长 |
| `PURCHASE_RECEIVED` | `purchase.received` | 采购入库 | 财务 / 库存 |
| `REIMBURSEMENT_APPROVED` | `reimbursement.approved` | 报销审批通过 | 财务 / 申请人 |
| `TOOL_ISSUE` | `tool.issue` | 工具领用 | 工具管理员 |
| `TOOL_RETURN` | `tool.return` | 工具归还 | 工具管理员 |
| `TOOL_DAMAGE` | `tool.damage` | 工具损坏报修 | 维护人员 / 店长 |

## 3. 优先级常量

`NotifyEvent.Priority`：

| 常量 | 值 | 使用场景 |
|------|---|---------|
| `LOW` | `low` | 信息类（如排班变更通知） |
| `NORMAL` | `normal` | 默认，常规业务通知 |
| `HIGH` | `high` | 需及时处理（如库存预警、退款审批） |
| `URGENT` | `urgent` | 紧急（如桌台超时占用、违约金告警） |

## 4. 接收者类型常量

`NotifyEvent.ReceiverType`：

| 常量 | 值 | receiverIds 含义 |
|------|---|----------------|
| `ALL` | `all` | null（全体可见） |
| `ROLE` | `role` | 角色ID列表（如 `"1,3"` = GM + 店长） |
| `STAFF` | `staff` | 员工ID列表（如 `"5,12,18"`） |
| `DEPT` | `dept` | 部门ID列表（如 `"2,3"` = 前厅 + 后厨） |

## 5. 消息流转

```
[业务方]                                    [消费者]
   ↓                                          ↑
NotifyPublisher.publish(event)                |
   ├──→ 同步落库 sys_notification            |
   └──→ MQ 发送（仅 app.notify.enabled=true）
            ↓
        [RabbitMQ youjian.notify.exchange]
            ↓ routing-key=notify.event
        [youjian.notify.queue]
            ↓
        NotifyConsumer.onNotify(event)
            ├──→ [TODO] WebSocket 推 KDS
            ├──→ [TODO] WebSocket 推前台看板
            └──→ [TODO] 短信通道
```

## 6. 使用示例

### 6.1 后端发布通知

```java
@Autowired
private NotifyPublisher notifyPublisher;

// 创建预订后发送通知
notifyPublisher.publish(NotifyEvent.builder()
    .eventType(NotifyEvent.NotifyType.BOOKING_CREATED)
    .storeId(booking.getStoreId())
    .title("新预订 " + booking.getBookingId())
    .content(booking.getCustomerName() + " " + booking.getGuestCount() + "人")
    .priority(NotifyEvent.Priority.NORMAL)
    .senderId(UserContext.getCurrentUserId())
    .senderName(UserContext.getCurrentUserName())
    .receiverType(NotifyEvent.ReceiverType.ALL)
    .relatedType("booking")
    .relatedId(savedBooking.getId())
    .triggerTime(LocalDateTime.now())
    .build());
```

### 6.2 双模式工作
- `app.notify.enabled=false`（默认）：**仅同步落库**，不发送 MQ，应用在无 RabbitMQ 环境下正常工作
- `app.notify.enabled=true`：**同步落库 + MQ 异步推送**，下游消费者分发到 KDS / 看板 / 短信

### 6.3 故障兜底
- MQ 发送失败：仅记录日志，不影响主业务（同步落库已确保数据不丢）
- 消费者异常：不抛异常，避免消息反复重投

## 7. 消息序列化

- **格式**：JSON
- **转换器**：`Jackson2JsonMessageConverter`
- **时间字段**：`LocalDateTime` 序列化为 `yyyy-MM-dd HH:mm:ss` 字符串（注册 `JavaTimeModule`）
- **字符集**：UTF-8

## 8. 队列/交换机配置

| 项 | 默认值 | 环境变量 |
|---|--------|---------|
| 队列名 | `youjian.notify.queue` | `app.notify.queue` |
| 交换机 | `youjian.notify.exchange` | `app.notify.exchange` |
| 路由键 | `notify.event` | `app.notify.routing-key` |
| 消息 TTL | 7 天 | 队列属性 `x-message-ttl` |
| 队列持久化 | true | durable |
| 重试次数 | 3 | `spring.rabbitmq.listener.simple.retry.max-attempts` |
| 重试间隔 | 1s 起步，×2 递增 | `spring.rabbitmq.listener.simple.retry.initial-interval` |
