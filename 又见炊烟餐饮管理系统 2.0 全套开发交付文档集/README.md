\## 重要通用约束（所有开发人员必读）

1\. 所有业务表禁止物理DELETE删除，统一使用 `is\_deleted` 逻辑删除；

2\. 全系统金额统一使用 `decimal(12,2)`，禁止使用浮点类型；

3\. 所有业务操作必须留存审计日志audit\_log；

4\. 所有状态枚举统一参考【01\_产品PRD/全局状态字典统一标准文档.docx】，禁止各自定义状态值；

5\. 所有SQL脚本统一编码：UTF-8；文档命名不含特殊字符，Windows/Mac/Linux全平台兼容。
