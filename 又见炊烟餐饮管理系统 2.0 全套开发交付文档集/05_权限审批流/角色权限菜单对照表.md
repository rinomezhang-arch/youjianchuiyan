## 1. RBAC 五表关系

```
sys_role ─┬─< sys_user_role >─ staff_master（用户）
          └─< sys_role_permission >─ sys_permission（权限点）
sys_menu.permission_code → sys_permission.permission_code（菜单关联权限）
```

## 6. 数据范围（data_scope）

| data_scope | 含义 | 适用 |
|-----------|------|------|
| `all` | 跨门店全局 | GM |
| `store` | 仅本门店 | 店长 / 员工 / 服务员 |

### 6.1 隔离实现
- **查询**：`StoreDataScopeAspect` 自动覆盖 storeId 参数
- **写入**：Controller 内调用 `UserContext.assertStoreAccess(targetStoreId)` 校验
- **越权**：返回 `403` 错误

## 7. 审批流（5 类）

| 审批类型 | 触发条件 | 审批人 | 备注 |
|---------|---------|-------|------|
| 采购申请审批 | 采购金额 > 阈值 | 店长 → GM | 阶梯审批 |
| 报销审批 | 报销金额 > 阈值 | 店长 → 财务 → GM | 三级审批 |
| 调价审批 | 售价变动 > 5% | 店长 → GM | |
| 排班审批 | 跨月调班 | 店长 | |
| 离职审批 | 员工离职申请 | 店长 → GM | |

### 7.1 审批状态机
```
[pending 待审批] ──通过──> [approved 已通过] ──执行──> [completed 已完成]
       │
       └──驳回──> [rejected 已驳回]
       │
       └──撤销──> [cancelled 已撤销]
```

### 7.2 审批超时
默认 48 小时（`config.approval.timeout_hours=48`），超时自动升级到上级审批人。

## 9. 自定义角色

新增角色步骤：
1. `INSERT INTO sys_role (role_code, role_name, store_id, data_scope, ...) VALUES (...)`
2. `INSERT INTO sys_role_permission (role_id, permission_id) VALUES ...`（批量）
3. `INSERT INTO sys_user_role (user_id, role_id) VALUES (...)`（分配给用户）

详细 SQL 见同目录 `各类审批流程初始化SQL.sql`。

## 10. 验证查询

```sql
-- 查询某用户的所有权限
SELECT
  u.username,
  r.role_name,
  p.permission_code,
  p.permission_name
FROM staff_master u
JOIN sys_user_role ur ON u.staff_id = ur.user_id
JOIN sys_role r ON ur.role_id = r.role_id
JOIN sys_role_permission rp ON r.role_id = rp.role_id
JOIN sys_permission p ON rp.permission_id = p.permission_id
WHERE u.staff_id = ?
ORDER BY p.permission_code;

-- 查询某角色可见的菜单
SELECT
  r.role_name,
  m.menu_name,
  m.path
FROM sys_role r
JOIN sys_role_permission rp ON r.role_id = rp.role_id
JOIN sys_permission p ON rp.permission_id = p.permission_id
JOIN sys_menu m ON m.permission_code = p.permission_code
WHERE r.role_id = ?
ORDER BY m.sort_order;
```
