## 1. 鉴权体系

### 1.1 JWT 鉴权流程

```
[客户端] -- Authorization: Bearer <token> --> [JwtAuthInterceptor]
                                                  ↓ 解析 JWT
                                              [UserContext] 注入用户身份
                                                  ↓
                                              [Controller] 业务处理
```

### 1.2 关键组件

| 组件 | 文件 | 职责 |
|------|------|------|
| `JwtAuthInterceptor` | `config/JwtAuthInterceptor.java` | 拦截 `requiresAuth` 路径，校验 JWT token |
| `IpadInterceptor` | `config/IpadInterceptor.java` | iPad 端独立鉴权（含设备校验） |
| `RateLimitInterceptor` | `config/RateLimitInterceptor.java` | 接口限流 |
| `UserContext` | `util/UserContext.java` | ThreadLocal 存储当前用户身份 |
| `AESUtil` | `util/AESUtil.java` | 敏感字段加解密 |

### 1.3 路由配置

`WebMvcConfig.java` 中配置拦截器：
```java
@Override
public void addInterceptors(InterceptorRegistry registry) {
    registry.addInterceptor(jwtAuthInterceptor)
            .addPathPatterns("/api/**")
            .excludePathPatterns(
                "/api/auth/login",
                "/api/auth/register",
                "/api/upload/public/**",
                "/api/ipad/**"  // iPad 走独立鉴权
            );
    registry.addInterceptor(ipadInterceptor)
            .addPathPatterns("/api/ipad/**");
    registry.addInterceptor(rateLimitInterceptor)
            .addPathPatterns("/api/**");
}
```

### 1.4 Token 规范
- **算法**：HS256
- **密钥**：环境变量 `JWT_SECRET`（生产强制，本地默认 `youjian-banquet-secret-key-2026`）
- **有效期**：access_token 24h
- **存储**：客户端 `localStorage`（前端），服务器端不存储
- **载荷**：
  ```json
  {
    "sub": "userId",
    "username": "...",
    "role": "GM|STORE_MANAGER|...",
    "storeId": 1,
    "dataScope": "all|store",
    "iat": 1234567890,
    "exp": 1234654290
  }
  ```

## 2. 门店数据隔离

### 2.1 设计目标
多门店（连锁）数据隔离，店长仅可操作本店数据，GM 跨门店。

### 2.2 关键字段
- `store_id`：所有业务表必带
- `UserContext.dataScope`：`all`（全局）/ `store`（仅本店）

### 2.3 切面实现

**`StoreDataScopeAspect.java`** 拦截所有 GET 请求，前置注入 `UserContext`：

```java
@Aspect
@Component
public class StoreDataScopeAspect {
    @Before("execution(* com.youjian.banquet.controller.*Controller.*(..))")
    public void beforeControllerMethod(JoinPoint joinPoint) {
        // 1. 从 JWT 解析用户身份 → UserContext
        // 2. 设置 currentStoreId / dataScopeAll
        // 3. 若 method 签名含 storeId 参数：
        //    - dataScope=all → 用客户端传入的 storeId
        //    - dataScope=store → 强制覆盖为 currentStoreId
    }
}
```

### 2.4 Controller 层使用模式

**查询接口**：
```java
@GetMapping("/customers")
public Result<List<Customer>> list(@RequestParam(defaultValue="1") Long storeId, ...) {
    // dataScope=store 时，storeId 已被切面覆盖为 currentStoreId
    // dataScope=all 时，storeId 保留客户端传入值
    return Result.success(customerRepo.findByStoreId(storeId));
}
```

**写接口**：
```java
@PostMapping("/customers")
@Transactional
public Result<Customer> create(@RequestBody CustomerMaster customer) {
    // 写接口需主动兜底设置 dataScopeAll 标记
    UserContext.ensureDataScopeFromStoreId();
    if (!UserContext.isDataScopeAll()) {
        // 店长强制使用本店 storeId，防止伪造
        customer.setStoreId(UserContext.currentStoreId());
    }
    // GM 使用请求体中的 storeId
    return Result.success(customerRepo.save(customer));
}
```

**单条越权访问防护**：
```java
@GetMapping("/customers/{id}")
public Result<Customer> get(@PathVariable Integer id) {
    CustomerMaster c = customerRepo.findById(id).orElse(null);
    if (c == null) return Result.error(404, "客户不存在");
    try {
        UserContext.assertStoreAccess(c.getStoreId());  // 非GM访问他店返回 403
    } catch (IllegalArgumentException e) {
        return Result.error(403, "无权限：仅可查看本店客户");
    }
    return Result.success(c);
}
```

### 2.5 UserContext API

| 方法 | 说明 |
|------|------|
| `UserContext.getCurrentUserId()` | 当前用户ID |
| `UserContext.getCurrentUserName()` | 当前用户名 |
| `UserContext.getCurrentStoreId()` | 当前门店ID |
| `UserContext.isDataScopeAll()` | 是否全局数据范围 |
| `UserContext.assertStoreAccess(targetStoreId)` | 越权断言，非 GM 访问他店抛 `IllegalArgumentException` |
| `UserContext.ensureDataScopeFromStoreId()` | 写接口兜底：基于 storeId 设置 dataScopeAll |

## 3. 全局异常处理

### 3.1 统一响应格式

```java
public class Result<T> {
    private int code;       // 200=成功 403=越权 404=不存在 500=失败
    private String message;
    private T data;
}
```

### 3.2 GlobalExceptionHandler

`exception/GlobalExceptionHandler.java` 统一捕获异常并返回 `Result.error(...)`：

| 异常 | HTTP 状态 | Result.code | 说明 |
|------|----------|------------|------|
| `IllegalArgumentException` | 400 | 400 | 参数非法 |
| `NoHandlerFoundException` | 404 | 404 | 接口不存在 |
| `AccessDeniedException` | 403 | 403 | 无权限 |
| `AuthenticationException` | 401 | 401 | 未认证 |
| `MaxUploadSizeExceededException` | 413 | 413 | 上传文件过大 |
| `DataIntegrityViolationException` | 409 | 409 | 数据完整性冲突（唯一约束等） |
| `Exception` | 500 | 500 | 兜底 |

### 3.3 Controller 层异常处理约定

Controller 内 try-catch 业务异常，返回 `Result.error(...)`，**不向上抛**，便于前端精准获取错误码：

```java
@PostMapping("/customers")
@Transactional
public Result<Customer> create(@RequestBody CustomerMaster customer) {
    try {
        // ...
        return Result.success(saved);
    } catch (Exception e) {
        // 显式回滚事务
        try { TransactionAspectSupport.currentTransactionStatus().setRollbackOnly(); } catch (Exception ignore) {}
        return Result.error(500, "创建客户失败: " + e.getMessage());
    }
}
```

### 3.4 跨域 CORS

`CorsConfig.java` 配置允许跨域：
```java
@Configuration
public class CorsConfig {
    @Bean
    public WebMvcConfigurer corsConfigurer() {
        return new WebMvcConfigurer() {
            @Override
            public void addCorsMappings(CorsRegistry registry) {
                registry.addMapping("/api/**")
                        .allowedOrigins("*")
                        .allowedMethods("GET", "POST", "PUT", "DELETE", "OPTIONS")
                        .allowedHeaders("*");
            }
        };
    }
}
```

Controller 上也可用 `@CrossOrigin(origins = "*")`。

## 4. 审计日志切面

### 4.1 AuditLogAspect

`aop/AuditLogAspect.java` 拦截写操作，记录到 `audit_log` 表：
- 拦截 `@PostMapping` / `@PutMapping` / `@DeleteMapping`
- 自动捕获操作人、操作时间、IP、请求路径、请求体
- 写入 `audit_log` 表

### 4.2 ChangeLog

业务关键变更（如修改价格、调整库存）由 Service 层主动调用：
```java
changeLogRepo.save(new ChangeLog()
    .setEntityType("dish")
    .setEntityId(dishId)
    .setFieldName("selling_price")
    .setOldValue("88.00")
    .setNewValue("98.00")
    .setOperatorId(UserContext.getCurrentUserId()));
```

## 5. 编码规范

### 5.1 UTF-8 编码过滤

`EncodingFilterConfig.java` 强制 UTF-8，避免中文乱码（特别是用户名/密码）：
```java
 FilterRegistrationBean<CharacterEncodingFilter> filter = new FilterRegistrationBean<>();
 filter.setFilter(new CharacterEncodingFilter("UTF-8", true));
```

### 5.2 Jackson 序列化

`JacksonConfig.java`：
- `LocalDateTime` 序列化为 `yyyy-MM-dd HH:mm:ss` 字符串
- `BigDecimal` 保留 2 位小数
- 关闭 `AUTO_CLOSE_TARGET` 防止 "Stream closed"
- 自定义 `IdCardSerializer` / `SensitiveDataSerializer` 脱敏敏感字段

## 6. 接口通用约束

1. **必带 storeId**：所有请求（GET `@RequestParam` / POST `@RequestBody`）必须带 `storeId`
2. **统一 Result**：所有接口返回 `Result<T>` 包装
3. **错误信息中文**：`Result.error(500, "...失败: " + e.getMessage())` 用中文，便于前端展示
4. **HTTP 方法**：GET 查询、POST 创建、PUT 修改、DELETE 删除（软删）
5. **路径规范**：`/api/<resource>[/{id}][/<action>]`，如 `/api/customers/123/history`
