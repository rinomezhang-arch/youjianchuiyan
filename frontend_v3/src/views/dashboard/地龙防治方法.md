## 第一步：先分清你说的"地龙"是哪种

| 真身 | 长什么样 | 危害方式 | 要不要杀 |
|------|---------|---------|---------|
| **蚯蚓**（中药正名"地龙"） | 环节状、红褐色 | 钻土松土、吃腐殖质 | **不用杀，是有益的** |
| **地老虎**（土蚕/切根虫） | 灰褐肉虫、卷成一团 | 夜里齐根咬断幼苗茎秆 | 必须治 |
| **蛴螬**（白土蚕） | 白胖、C字形 | 啃食根系，苗发黄蔫萎 | 必须治 |

关键判断：**白天翻土找不到虫、夜里苗被齐根咬断**＝地老虎；**苗慢慢发黄、根被啃残**＝蛴螬；**只是看到土里有蚯蚓在钻**＝别管它，它在帮你松土改土。

## 第二步：如果确实是害虫，根治就这三招

**1. 拌种（播种前最省事）**
- 噻虫嗪悬浮种衣剂，按药:种子=1:200-300 拌种，阴干后播种
- 地老虎、蛴螬通杀，几块钱一亩，虫子闻味就不敢靠

**2. 撒施（已经种下去的地）**
- 每亩用 3% 辛硫磷颗粒剂 3-4kg，或 2% 吡虫啉颗粒剂 1-2kg 拌细土/有机肥，顺垄撒在苗根旁
- 傍晚撒效果最好，因为这类虫是夜行的

**3. 灌根（虫已经爆发、苗在断）**
- 50% 辛硫磷乳油 800-1500 倍液，或 25% 噻虫嗪 1500 倍液灌根
- **傍晚灌**，让药渗进土层，虫子晚上一出来就碰到药

### 致命缺陷（这就是"治不好"的守护层原因）

**1. 不是守护进程，只是"登录启动器"**
- schtasks Schedule Type = `At logon time`，**仅交互登录时触发一次**
- 无重复触发、无崩溃检测、无自动重启
- 进程一挂就没人拉起，下次登录才再启

**2. gateway.cmd 不加载 .env —— 计划任务启动的网关根本没有 API key**
- [gateway.cmd](file:///C:/Users/rinom/.openclaw/gateway.cmd#L3) 只 `set` 了 `OPENCLAW_SERVICE_MANAGED_ENV_KEYS=DASHSCOPE_API_KEY,DEEPSEEK_API_KEY,...` 这个**名字列表**，但**从未 set 这些变量的实际值**，也没有 `source .env` 逻辑
- Windows cmd 不会自动读 .env
- 结果：schtasks 启动的网关进程 `DEEPSEEK_API_KEY` 为空 → 一调就 401/失败 → 这就是 schtasks Last Result=0 但"立即退出/不工作"的真相

**3. pid 文件不同步**
- [gateway.pid](file:///C:/Users/rinom/.openclaw/gateway.pid) 写的是 `43232`，但实际网关进程是 `12460` —— 计划任务启动的 43232 早就死了，pid 文件没更新

**4. 当前活着的 12460 不是守护拉起的**
- ParentProcessId=5680（cmd.exe），21:01:11 启动
- 这是**某个 cmd 终端手动 `openclaw gateway run` 启动的前台进程**，不是 schtasks 管理的
- 那个 cmd 窗口一关，12460 可能跟着死 → 地龙又没了

**5. nssm 已下载但没装服务**
- [C:\Users\rinom\.openclaw\nssm\nssm.exe](file:///C:/Users/rinom/.openclaw/nssm/nssm.exe) 存在，但 `Get-Service` 查不到任何 openclaw/gateway 服务 —— 没用上
