# 零点用餐场景设计文档

> 微龙整理 | 2026-07-31

## 一、概述

宴会预订之外的日常散客用餐场景，覆盖家庭聚餐、朋友聚会、独自用餐、快餐等。

## 二、场景清单

### 1. 小聚（2-4人）

| 维度 | 说明 |
|------|------|
| 用餐时段 | 午11:30-13:00 / 晚17:30-20:00 |
| 桌型偏好 | 散座、小包间 |
| 菜品选择 | 单点，3-5道菜 |
| 人均消费 | 50-80元 |
| 关键需求 | 上菜快、口味好 |

**流程**：
1. 到店 → 引导入座
2. 扫码点单或服务员下单
3. 厨房出菜
4. 用餐 → 结账

### 2. 家庭聚餐（5-10人）

| 维度 | 说明 |
|------|------|
| 用餐时段 | 午12:00-14:00 / 晚18:00-21:00 |
| 桌型偏好 | 中包间（400包间）、大桌散座 |
| 菜品选择 | 单点+套餐推荐，6-12道菜 |
| 人均消费 | 80-150元 |
| 关键需求 | 小孩座椅、老人友好菜品、安静环境 |

**流程**：
1. 提前打电话预留桌位（非宴会不走预订系统）
2. 到店 → 入座 → 点菜
3. 按家庭需求推荐菜品（老少皆宜）
4. 结账（可积分、可挂账）

### 3. 朋友聚会（4-8人）

| 维度 | 说明 |
|------|------|
| 用餐时段 | 晚18:00-22:00 |
| 桌型偏好 | 包间（300/400包间） |
| 菜品选择 | 硬菜为主+下酒菜，8-12道 |
| 人均消费 | 100-200元 |
| 关键需求 | 私密聊天空间、酒水服务、不限时 |

**流程**：
1. 预订包间（2小时起）
2. 到店 → 入座包间
3. 点菜+酒水
4. 用餐/聊天 → 可延长包间时间
5. 结账

### 4. 个人/双人用餐（1-2人）

| 维度 | 说明 |
|------|------|
| 用餐时段 | 午11:30-13:00 / 晚17:30-20:00 |
| 桌型偏好 | 散座、大厅 |
| 菜品选择 | 单点2-4道菜 |
| 人均消费 | 40-80元 |
| 关键需求 | 出餐快、不占大桌 |

**流程**：到店 → 散座 → 扫码点单 → 用餐 → 结账

### 5. 外卖/外带

| 维度 | 说明 |
|------|------|
| 时段 | 全天营业时间 |
| 渠道 | 电话、微信、外卖平台 |
| 菜品 | 简餐为主，部分硬菜支持外带 |
| 关键需求 | 包装完好、出餐快 |

**流程**：
1. 客户电话/微信/平台下单
2. 厨房制作
3. 打包 → 客户自取或骑手配送
4. 确认收餐 → 结账

### 6. 团体用餐（20-50人不走宴会）

| 维度 | 说明 |
|------|------|
| 用餐时段 | 午/晚 |
| 桌型偏好 | 扶摇厅（半厅）、大厅拼桌 |
| 菜品选择 | 客制套餐，人均80-150元 |
| 关键需求 | 统一菜单、统一结算 |
| 区别 | 不走宴会预订系统，走零点+团体优惠 |

**流程**：
1. 对接负责人确认人数
2. 统一菜单（可2-3档套餐选择）
3. 自助或服务员协助分菜
4. 单桌或统一结账

## 三、零点用餐通用功能需求

| 功能 | 说明 |
|------|------|
| 扫码点单 | 每桌二维码，客户手机扫码点单 |
| 加菜 | 用餐中途支持手机加菜 |
| 退菜 | 未出品菜品支持退换 |
| 结账 | 支持现金/微信/支付宝/签单 |
| 发票 | 支持电子发票 |
| 团购核销 | 美团/抖音团购券核销 |
| 会员积分 | 自动累计积分 |
| 拼桌 | 大厅多桌拼成大桌 |
